# 水保計畫輔助系統 基礎版 — 下載與安裝

> 這是**基礎版**的安裝程式與更新來源。基礎版只開放部分功能(專案資料、第一~四章 Word、坡度/坡向、鑽探、植生、
> 排水設施斷面與集水井、擋土牆、沉砂滯洪池、工具);水理計算、整地、道路、造價等僅限完整版,畫面上會暗掉並提示。
> 完整版請至 [SWC_APP-releases](https://github.com/ji3g4vul394-creator/SWC_APP-releases)。

## 下載與安裝

1. 點右側 **Releases**,下載 **`SWCAppBasic-basic-Setup.exe`**(其他檔案是程式自動更新用的,不必下載)。
2. 執行安裝程式。不需要管理員權限,程式裝到你自己的使用者資料夾(`%LocalAppData%\SWCAppBasic`)。
   Windows 若出現「Windows 已保護你的電腦」(SmartScreen):點 **其他資訊 → 仍要執行**。
3. 安裝完成會自動開啟程式,桌面與開始功能表會有「水保計畫輔助系統 基礎版」捷徑。
4. 第一次開啟會出現授權畫面:按 **複製裝置碼**,把裝置碼傳給設計者,收到**基礎版授權檔**(`*.swclic`)後按 **匯入授權檔**。
   基礎版與完整版的授權檔互不通用。

## 與完整版並存

基礎版與完整版可以裝在同一台電腦:安裝目錄、捷徑、授權檔、更新來源都分開,互不影響。
雙擊 `.swcp` 專案檔時,若電腦上有完整版,一律以完整版開啟。基礎版可以開啟完整版存的專案檔,沒有的內容會原樣保留。

## 更新

基礎版只在有需要時發布新版,程式開啟時會自動檢查這裡;有新版時標題列版本號旁會有一個小圓點。

## 系統需求

- Windows 10(2018 年 4 月更新以後)或 Windows 11,64 位元。
- Microsoft Edge WebView2 Runtime(Windows 11 內建;缺少時程式會提示並開啟微軟下載頁)。
- DWG 匯入/匯出需要本機安裝 AutoCAD 2013 以上(含 LT);沒有 AutoCAD 時以 DXF 匯入/匯出。
